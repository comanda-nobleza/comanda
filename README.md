# Comanda

Sistema de control de Nobleza Beauty Room. Se usa en **https://comanda.noblezabeauty.com**.

- `src/app.html` — la app (fuente).
- `web.js` — conexión con Firebase (base de datos, acceso, descargas y archivos).
- `tools/build.py` — genera `index.html` a partir de `src/app.html`.
- `fotos/` — fotos del inventario.

Los datos **no** están en este repositorio: viven en Firebase y solo se ven con la contraseña del salón.
